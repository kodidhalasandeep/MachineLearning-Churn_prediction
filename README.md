# MachineLearning-Churn_prediction
A machine learning classification model built with "Python" and "Scikit-Learn"to predict customer churn risk for subscription-based services.
Features
- **Vehicle Registration:** Easily register customer details and service notes.
- **Status Tracking:** Update service stages (e.g., *In Progress*, *Ready for Pickup*).
- **Automated Alerts:** Instantly triggers notifications when a vehicle is ready.

## Tech Stack
- **Backend:** Python, FastAPI, Pydantic
- **Database:** SQLite
- **Notifications:** Twilio API / Simulation Engine
